A new version of the Acoustid fingerprinter has been released. The version adds support for Unicode file names on Windows, reading 24-bit audio file formats and can parse MBID tags from MP3 files written by foo_musicbrainz . Download: Windows application (7.5M) Mac OS X application (14.4M) Source code tarball (70K) Changes since version 0.4: Unicode filename support on Windows.
