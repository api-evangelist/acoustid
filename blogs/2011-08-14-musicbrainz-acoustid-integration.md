**Update: **As of Jan 12, 2012 , Acoustid links are now displayed on MusicBrainz by default. While the Acoustid database is reimporting, I wanted to do something fun, so tried to integrate Acoustid links into the MusicBrainz website. I wrote a simple user script that calls the Acoustid API, loads all IDs linked to a recording and displays the data right next to the list of PUIDs.
